# IT Support Troubleshooting Knowledge Base

## Project Overview
This project is a beginner-level IT Support portfolio project that documents common Windows, hardware, software, and network troubleshooting procedures.

## Project Objectives
- Document common IT support problems.
- Organize troubleshooting steps into clear guides.
- Record issues, actions, verification methods, and outcomes.
- Practice structured troubleshooting documentation.
- Build a portfolio project demonstrating foundational IT support skills.

## Troubleshooting Guides
The project includes guides covering:
- No internet connection
- Printer not printing
- Slow computer
- Application not opening
- Windows Update problems
- Keyboard and mouse problems
- Low storage space
- Browser problems
- Shared folder access
- Software installation problems
- Password and account access

## Project Files
- `troubleshooting-guides/` — Troubleshooting documentation
- `troubleshooting-log/` — Excel troubleshooting log
- `evidence/screenshots/` — Screenshots from actual practice, where available
- `documentation/` — Project documentation and troubleshooting process

## Testing and Limitations
The troubleshooting log contains sample records. Each record must be clearly identified as simulated or updated with accurate details from actual practice. Procedures that have not been tested on a real device must be marked as documentation only.

## Safety Practices
- Do not disable antivirus or firewall protections.
- Do not delete unknown system files.
- Use official software sources.
- Do not bypass passwords or access permissions.
- Escalate issues that require administrator access or authorization.
