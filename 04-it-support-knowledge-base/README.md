# IT Support Troubleshooting Knowledge Base

A beginner-level IT Support portfolio project documenting common Windows, hardware, software, and network troubleshooting procedures.

## Project Overview

This project organizes troubleshooting guides and an Excel issue log to demonstrate structured problem-solving, technical documentation, and basic IT support knowledge.

## Troubleshooting Topics

1. No Internet Connection
2. Printer Not Printing
3. Slow Computer
4. Application Not Opening
5. Windows Update Problems
6. Keyboard and Mouse Problems
7. Low Storage Space
8. Browser Problems
9. Shared Folder Access
10. Software Installation Problems
11. Password and Account Access

## Testing and Accuracy

Some troubleshooting log entries may be simulated examples. Simulated records must not be presented as real customer incidents or verified practical tests.

Procedures that have not been tested on an actual device should be identified as documentation only. Practical testing should be performed safely and with proper authorization.

## Safety Guidelines

- Use official software sources.
- Do not disable security protections as a routine troubleshooting step.
- Do not delete unknown system files.
- Do not bypass account passwords or access permissions.
- Escalate issues requiring administrator access or authorization.
