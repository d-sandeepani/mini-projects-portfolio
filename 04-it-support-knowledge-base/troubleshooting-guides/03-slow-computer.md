# Troubleshooting Guide 03: Slow Computer

## Scenario
A user reports that their Windows computer takes a long time to start, applications respond slowly, or everyday tasks take longer than expected.

## Symptoms
- Windows starts slowly.
- Applications take a long time to open.
- The computer freezes or becomes temporarily unresponsive.
- Switching between applications is slow.

## Possible Causes
- Too many applications are running.
- Available storage space is low.
- A background task is using significant system resources.
- Pending updates or a required restart.
- An application problem.
- Possible hardware or malware-related issues.

## Initial Checks
1. Ask when the slowdown started.
2. Check whether one application or the whole computer is affected.
3. Check whether an update or installation is in progress.
4. Check available storage space.
5. Save open work before restarting the computer.

## Step-by-Step Troubleshooting
1. Save your work and close applications that are not needed.
2. Restart the computer if appropriate and permitted.
3. Press Ctrl + Shift + Esc to open Task Manager.
4. In Task Manager, inspect CPU, Memory, and Disk usage.
5. Identify applications using significant resources, but do not end unfamiliar system processes.
6. Open Windows Settings and check available storage under System > Storage. Menu names may vary by Windows version.
7. If storage is low, use Windows Storage settings to review temporary files. Check the listed items carefully before removing anything.
8. Check Windows Update for pending updates. Install approved updates when appropriate.
9. Observe whether performance improves after each action.
10. Record the actions taken and the actual results.

Do not delete system files, disable security software, or change advanced system settings as a routine fix.

## Verification
- Open the applications that were previously slow.
- Check whether startup and normal tasks respond more quickly.
- Record whether performance improved, remained unchanged, or became worse.

## Escalation
Escalate the issue if the computer continues to freeze, shows repeated errors, makes unusual hardware noises, or may have a hardware fault or malware infection.

## Prevention
- Keep unnecessary applications closed.
- Maintain adequate free storage space.
- Install approved updates.
- Use approved security software.
- Restart the computer when required.

## Documentation

Problem: Computer running slowly.
Initial checks: Task Manager and available storage checks documented.
Action: Resource usage reviewed and unnecessary applications closed.
Verification: Check whether performance improves.
Outcome: resolved.
Status: resolved.
