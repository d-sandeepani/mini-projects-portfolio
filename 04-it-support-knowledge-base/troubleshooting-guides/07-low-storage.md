# Troubleshooting Guide 07: Low Disk Space / Storage Problem

## Scenario
A computer displays a low storage warning, cannot save files, or has insufficient available disk space for normal tasks or updates.

## Symptoms
- Windows displays a low disk space warning.
- The computer cannot save new files.
- Software updates cannot complete because of insufficient storage.
- Applications report that there is not enough space.
- Available storage is nearly full.

## Possible Causes
- Many files stored on the computer.
- Large downloads or unused personal files.
- Temporary files and cached data.
- Applications using substantial storage.
- Recycle Bin contents occupying space.
- Limited disk capacity.

## Initial Checks
1. Record the low-storage warning or error message.
2. Open Windows Settings and navigate to System > Storage.
3. Identify which drive is low on space.
4. Review the storage categories and their reported sizes.
5. Ask whether the problem started after downloading or installing something.
6. Check whether the computer is managed by an organization and whether storage cleanup requires approval.

## Step-by-Step Troubleshooting
1. Save open work before making changes.
2. Open Settings > System > Storage.
3. Review which categories are using the most storage.
4. Check the Downloads folder for files you recognize and no longer need.
5. Move or remove only personal files you have confirmed are unnecessary and have permission to manage.
6. Review the Recycle Bin before emptying it. Emptying it permanently removes the files stored there.
7. Use Windows Storage settings or the built-in cleanup recommendations when available.
8. Read each cleanup option carefully before selecting it.
9. Do not delete unfamiliar system files, application folders, or files belonging to other users.
10. If storage remains low, consult the authorized IT administrator before making further changes.
11. Record the actions taken and the actual result.

Do not use unofficial cleanup utilities or remove important files simply to free space.

## Verification
- Reopen Settings > System > Storage.
- Check whether available storage has increased.
- Confirm whether the original warning is still displayed.
- Check whether the affected task can now be completed, if appropriate.
- Record the actual outcome.

## Escalation
Escalate if the drive remains nearly full, storage figures appear unusual, disk errors are reported, or important system or organizational files may be involved.

## Prevention
- Review storage usage periodically.
- Organize personal files into appropriate folders.
- Remove unnecessary files only after checking them.
- Use approved storage locations for backups.
- Keep sufficient free space for updates and normal operations.
