# Troubleshooting Guide 08: Browser Problems

## Scenario
A web browser does not load websites correctly, becomes unresponsive, displays repeated errors, or behaves unexpectedly.

## Symptoms
- Websites do not load.
- The browser freezes or closes unexpectedly.
- Pages display incorrectly.
- The browser displays certificate or connection warnings.
- The browser becomes unusually slow.
- Downloads do not complete.

## Possible Causes
- An internet connection problem.
- A temporary browser issue.
- Corrupted cached data or cookies.
- An outdated browser version.
- A problematic browser extension.
- A website service problem.
- Security or network restrictions.

## Initial Checks
1. Record the website address and exact error message.
2. Check whether other websites load.
3. Check whether another browser can access the same website, if available.
4. Check whether other applications can access the internet.
5. Determine whether the problem affects one website or multiple websites.
6. Check whether the browser recently updated or an extension was installed.

## Step-by-Step Troubleshooting
1. Record the error message before changing settings.
2. Try reloading the affected webpage.
3. Confirm that the computer has a working internet connection.
4. Close unnecessary browser tabs and check whether the browser responds.
5. Close and reopen the browser after saving any important work.
6. Check for browser updates using the browser's built-in update settings.
7. If the problem appears limited to one website, check whether the website is available through an approved alternative or official status page.
8. If appropriate, clear cached images and files using the browser's built-in privacy or browsing-data settings.
9. Read the available options carefully before clearing data. Avoid deleting saved passwords or other important browsing data unless specifically intended and authorized.
10. If the problem continues, consult the browser's official support guidance or contact the authorized IT administrator.

Do not bypass certificate warnings, install unknown extensions, or change organizational security settings to access a website.

## Verification
- Reopen the affected website.
- Check whether pages load and respond normally.
- Confirm whether the original error remains.
- Record the actual result and any remaining symptoms.

## Escalation
Escalate if multiple websites remain inaccessible, certificate warnings persist, organizational websites are affected, or the problem appears related to security or network restrictions.

## Prevention
- Keep the browser updated.
- Install extensions only from trusted and approved sources.
- Review browsing-data cleanup options before deleting information.
- Avoid suspicious links and downloads.
- Record recurring browser errors.
