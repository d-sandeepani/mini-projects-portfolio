# Troubleshooting Guide 11: Password and Account Access Problem

## Scenario
A user cannot sign in to a Windows computer or account because of a password error, account lockout, or another authentication problem.

## Symptoms
- The password is rejected.
- Windows displays an incorrect-password message.
- The account appears locked.
- The user cannot complete the sign-in process.
- A work or school account requires additional verification.
- The user cannot access an account after a password change.

## Possible Causes
- An incorrect password was entered.
- The wrong user account was selected.
- The keyboard layout or Caps Lock setting is affecting input.
- The account is locked or disabled.
- The password has expired.
- An organization requires additional authentication.
- A network or account service problem is affecting sign-in.

## Initial Checks
1. Record the exact error message without recording the password.
2. Confirm that the correct account is selected.
3. Check Caps Lock and the keyboard layout.
4. Determine whether the account is personal, local, or managed by an organization.
5. Ask whether the password was changed recently.
6. Check whether the message mentions an account lockout or additional verification.

## Step-by-Step Troubleshooting
1. Read the sign-in error message carefully.
2. Confirm the selected account and keyboard input settings.
3. If available, use the sign-in options provided by Windows.
4. For a personal Microsoft account, use Microsoft's official account recovery process.
5. For a work or school account, follow the organization's approved password-reset or identity-verification process.
6. If the account is locked or disabled, contact the authorized administrator or account support team.
7. Follow all required identity-verification procedures before requesting a reset.
8. Record the actions taken and the actual result, without recording passwords, recovery codes, or authentication secrets.
9. If access is not restored, document the issue as unresolved and escalate it.

Never attempt to bypass sign-in security, access another person's account, or collect another person's password.

## Verification
- Confirm whether the user can sign in using the authorized recovery process.
- Check whether the original error remains.
- Confirm access only to the intended account.
- Record the actual outcome without storing authentication secrets.

## Escalation
Escalate if the account remains locked, identity verification fails, the account may be compromised, or administrator intervention is required.

## Prevention
- Use a strong, unique password.
- Keep recovery information up to date.
- Enable approved multi-factor authentication when available.
- Never share passwords or verification codes.
- Report unexpected sign-in alerts promptly.
