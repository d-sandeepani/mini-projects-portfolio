# Troubleshooting Guide 01: No Internet Connection

## Scenario
A user reports that their Windows computer cannot access websites. Other applications may also show that there is no internet connection.

## Symptoms
- Websites do not load.
- Windows shows a network connection warning.
- Applications report that they are offline.

## Possible Causes
- Wi-Fi is disconnected.
- The network cable is loose.
- The router or internet service has a problem.
- The computer has an incorrect network configuration.
- The problem affects only one website or application.

## Initial Checks
1. Check whether Wi-Fi is enabled.
2. If using a network cable, check that it is securely connected.
3. Check whether other websites open.
4. If permitted, check whether another device can access the same network.
5. Ask whether other users are experiencing the same issue.

## Step-by-Step Troubleshooting
1. Identify the exact error message.
2. Open Windows Settings and select Network & internet.
3. Check whether Wi-Fi or Ethernet shows as connected.
4. If Wi-Fi is disconnected, select the correct network and connect using the authorized password.
5. Open a different trusted website to check whether the issue affects one website only.
6. Restart the browser and try again.
7. Use the built-in Windows network troubleshooter if available.
8. If the issue continues, contact the authorized network administrator or internet service provider as appropriate.
9. Record every action and its actual result.

Do not reset the router or change network settings without permission.

## Verification
- Open a trusted website.
- Confirm whether the page loads successfully.
- If the issue remains, record the result as unresolved.
- Do not mark the issue as resolved without checking the outcome.

## Escalation
Escalate the issue if several devices are affected, the network connection remains unavailable, administrator permissions are required, or the problem appears to involve network equipment or the internet service provider.

## Prevention
- Keep network cables securely connected.
- Use approved network settings.
- Report repeated connection problems.
- Follow organizational network policies.
