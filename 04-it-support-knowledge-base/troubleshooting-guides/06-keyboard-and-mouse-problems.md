# Troubleshooting Guide 06: Keyboard and Mouse Problems

## Scenario
A computer keyboard or mouse does not respond correctly, disconnects, or works intermittently.

## Symptoms
- Keyboard keys do not respond.
- Mouse movement does not work.
- Mouse clicks are not registered.
- A wireless keyboard or mouse disconnects.
- The device works intermittently.

## Possible Causes
- A loose or disconnected cable.
- A depleted wireless-device battery.
- A temporary computer problem.
- A faulty USB port.
- A wireless connection or receiver issue.
- A device driver or hardware problem.

## Initial Checks
1. Identify whether the keyboard, mouse, or both devices are affected.
2. Check whether the device is wired or wireless.
3. Look for visible cable damage.
4. Check whether the wireless device has power and whether its battery may need charging or replacement.
5. Check whether the problem affects other applications or the entire computer.
6. Ask whether the problem started after a recent change.

## Step-by-Step Troubleshooting
1. Save any open work if the computer is still responding.
2. Check that the keyboard or mouse cable is connected securely.
3. If it is a wireless device, check its power switch and battery.
4. If appropriate, reconnect the device using the manufacturer's instructions.
5. If the device uses USB, try another available USB port if permitted.
6. Test the device in another application.
7. If the computer is responsive and it is safe to do so, restart it after saving open work.
8. If the issue continues, check Windows device settings and consult approved support guidance.
9. Contact the authorized IT administrator if driver changes, hardware replacement, or additional permissions are required.
10. Record every action and its actual result.

Do not force connectors into ports, open computer hardware unnecessarily, or install drivers from unofficial websites.

## Verification
- Test keyboard typing in a text field.
- Test mouse movement and clicking.
- Confirm whether the device works consistently.
- Record any remaining problems.

## Escalation
Escalate if the device has visible damage, repeatedly disconnects, does not work after basic checks, or requires hardware replacement or administrator access.

## Prevention
- Handle devices and cables carefully.
- Keep liquids away from computer equipment.
- Charge or replace wireless-device batteries as needed.
- Use approved device drivers.
- Report damaged equipment promptly.
