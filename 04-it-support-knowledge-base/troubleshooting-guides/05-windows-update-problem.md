# Troubleshooting Guide 05: Windows Update Problem

## Scenario
A Windows computer cannot download or install an update, or Windows Update displays an error message.

## Symptoms
- An update download remains at the same percentage.
- An update installation fails.
- Windows Update displays an error code.
- Windows repeatedly asks for a restart.
- An update check does not complete.

## Possible Causes
- A temporary internet connection problem.
- Insufficient available storage.
- A temporary Windows Update service issue.
- A pending restart.
- An update compatibility issue.
- A problem requiring administrator or IT support.

## Initial Checks
1. Record the exact error message or error code.
2. Check whether the internet connection works.
3. Check available storage space.
4. Check whether a restart is pending.
5. Confirm whether the computer is managed by an organization and whether updates require approval.

## Step-by-Step Troubleshooting
1. Save all open work.
2. Confirm that the internet connection is working.
3. Open Windows Settings.
4. Navigate to Windows Update. The menu location may vary by Windows version.
5. Record the current update status and any displayed error code.
6. If a restart is pending, save your work and restart the computer when appropriate.
7. Check available storage under System > Storage.
8. If storage is low, review the items listed in Windows Storage settings before removing anything.
9. Run the built-in Windows Update troubleshooter if it is available.
10. Check Windows Update again and record the actual result.
11. If the error continues, consult official Microsoft support guidance or contact the authorized IT administrator.

Do not disable security software, download unofficial update files, or change advanced system settings without authorization.

## Verification
- Open Windows Update again.
- Check whether the update completes or the same error remains.
- Record the actual status and any error code.
- If the issue remains, document it as unresolved.

## Escalation
Escalate if updates repeatedly fail, an error code persists, the device is organization-managed, or the update problem affects security or normal operation.

## Prevention
- Install approved Windows updates regularly.
- Maintain sufficient available storage.
- Use a reliable internet connection.
- Restart the computer when required.
- Record recurring update errors.
