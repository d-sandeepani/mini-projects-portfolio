# Troubleshooting Guide 10: Software Installation Problem

## Scenario
A user cannot install an application on a Windows computer, or the installation process displays an error or stops unexpectedly.

## Symptoms
- The installer will not open.
- The installation stops before completion.
- An error message or error code appears.
- The installer reports insufficient storage.
- Windows requests administrator approval.
- The installed application does not start.

## Possible Causes
- The installer is damaged or incomplete.
- The software is incompatible with the operating system.
- There is insufficient available storage.
- A required component is missing.
- Administrator approval is required.
- Organizational policies restrict software installation.
- A previous installation needs attention.

## Initial Checks
1. Record the application name and exact error message.
2. Confirm where the installer was obtained.
3. Check whether the software supports the installed Windows version.
4. Review available storage space.
5. Check whether the computer is managed by an organization.
6. Determine whether administrator approval is required.
7. Ask whether the installation has failed before or is a new issue.

## Step-by-Step Troubleshooting
1. Stop and record the error message before retrying the installation.
2. Confirm that the installer came from the official software publisher or an organization-approved source.
3. Check the publisher's official requirements for Windows compatibility.
4. Review available storage in Windows Settings > System > Storage.
5. Close unnecessary applications and save any open work.
6. If the installer appears incomplete, obtain a fresh copy from the official or approved source, if permitted.
7. If Windows requests administrator approval, follow the authorized approval process.
8. Do not bypass organizational restrictions or use another person's administrator credentials.
9. If the software was previously installed, consult the publisher's official repair or uninstall guidance before making changes.
10. Record each action and its actual result.
11. If the issue continues, contact the authorized IT administrator or the software publisher's support team.

Do not disable security protections, run unknown installers, or change system permissions without authorization.

## Verification
- Check whether the installer completed successfully.
- Confirm that the application appears in the appropriate installed-apps list.
- If permitted, open the application and check whether it starts normally.
- Record any remaining error or unresolved issue.

## Escalation
Escalate if administrator approval is required, the software is blocked by organizational policy, the installer raises a security warning, or installation failures continue.

## Prevention
- Obtain software from official or approved sources.
- Check system requirements before installation.
- Keep sufficient storage available.
- Follow organizational software approval procedures.
- Record installation errors for future troubleshooting.
