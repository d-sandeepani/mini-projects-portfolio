# Troubleshooting Guide 09: Shared Folder Access Problem

## Scenario
A user cannot access a shared folder on a network or receives an access-denied message when trying to open it.

## Symptoms
- The shared folder cannot be opened.
- Windows displays an access-denied message.
- The network path cannot be found.
- The shared folder is not visible.
- The user is prompted for credentials unexpectedly.
- Access worked previously but has stopped.

## Possible Causes
- A network connection problem.
- An incorrect or outdated network path.
- The computer hosting the folder is unavailable.
- The user does not have the required permissions.
- Authentication or saved-credential issues.
- The shared folder or network service is unavailable.
- Organizational security policies restrict access.

## Initial Checks
1. Record the exact error message.
2. Confirm the shared folder path provided by the authorized owner or IT team.
3. Check whether the computer is connected to the required network.
4. Determine whether the issue affects one user or multiple users, if this information is available.
5. Ask whether the user could access the folder previously.
6. Confirm whether the device is managed by an organization.

## Step-by-Step Troubleshooting
1. Record the full error message and the shared folder path, while avoiding disclosure of confidential information.
2. Confirm that the computer has the required network connection.
3. Check that the shared folder path has been entered correctly.
4. If appropriate, ask the authorized folder owner whether the shared resource is available.
5. Check whether other approved network resources are accessible.
6. If Windows requests credentials, use only the user's authorized account and follow the organization's authentication process.
7. If an access-denied message appears, ask the folder owner or authorized administrator to review the user's permissions.
8. If the network path cannot be found, contact the authorized IT team to check the host and network availability.
9. Record each check and its actual result.
10. Do not change permissions or network security settings without authorization.

Do not bypass access controls, use another person's credentials, or share passwords.

## Verification
- Retry the shared folder path using the authorized account.
- Confirm whether the intended folder opens.
- Verify that access is limited to the resources the user is authorized to use.
- If access still fails, record the error and leave the issue unresolved.

## Escalation
Escalate if the host is unavailable, multiple users are affected, access permissions need changing, or the issue may involve confidential data or a security policy.

## Prevention
- Use approved shared folder paths.
- Request access through the authorized process.
- Review access permissions when responsibilities change.
- Report unexpected access-denied messages.
- Never share account passwords.
