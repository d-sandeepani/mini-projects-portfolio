# Troubleshooting Guide 02: Printer Not Printing

## Scenario
A user sends a document to print, but the printer does not produce the expected pages. The document may remain in the print queue, or the printer may show an error.

## Symptoms
- Nothing prints.
- A document remains in the print queue.
- The printer shows an error or offline status.
- The printed page is blank or incomplete.

## Possible Causes
- The printer is switched off or disconnected.
- Paper is missing or incorrectly loaded.
- Ink or toner is low or empty.
- The wrong printer is selected.
- A paper jam or printer error has occurred.
- The print queue or connection has a problem.

## Initial Checks
1. Check whether the printer is powered on.
2. Check the paper tray and printer display for warnings.
3. Check the USB cable or approved network connection.
4. Confirm that the correct printer is selected.
5. Check whether the printer has paper and sufficient ink or toner.

## Step-by-Step Troubleshooting
1. Identify the error message shown on the computer or printer.
2. Open Windows Settings and select Bluetooth & devices, then Printers & scanners. Menu names may vary by Windows version.
3. Select the required printer and check its status.
4. Confirm that the correct printer is selected in the application.
5. Open the print queue and check whether documents are paused or showing an error.
6. If authorized, resume a paused queue or cancel only the affected user's unwanted print job.
7. Check for a paper jam using the manufacturer's instructions. Do not force printer parts.
8. If appropriate, print a test page using the printer settings.
9. Record the action taken and the actual result.

Do not change shared printer settings or clear other users' print jobs without permission.

## Verification
- Print a test page or an approved sample document.
- Confirm that the page prints correctly.
- If printing still fails, record the issue as unresolved.

## Escalation
Escalate the issue if there is a hardware fault, a recurring paper jam, a persistent printer error, a suspected driver problem, or a shared printer configuration issue requiring administrator access.

## Prevention
- Load paper correctly.
- Follow the printer manufacturer's maintenance instructions.
- Check ink or toner levels.
- Report recurring errors promptly.
