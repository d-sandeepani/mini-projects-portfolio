# AI-Assisted Customer Support Workflow

**Project Type:** Personal Portfolio Project  
**Business Scenario:** NovaCart — Fictional Online Retail Store  
**Status:** In Progress

## 1. Project Overview

This project demonstrates how AI tools can assist with a simple customer support workflow by categorizing fictional customer messages and preparing draft responses for human review.

NovaCart is a fictional online retail business created exclusively for this demonstration. This project is not a real company deployment.

## 2. Business Problem

Customer support teams may receive messages about orders, refunds, deliveries, product questions, and complaints.

Categorizing messages and preparing initial responses manually can require time and consistent processes.

This project explores how AI can assist with these tasks while keeping a human responsible for reviewing responses and making business decisions.

## 3. Project Objectives

- Create a small dataset of fictional customer messages.
- Use an AI prompt to categorize messages into predefined categories.
- Compare AI predictions with expected categories.
- Generate professional draft responses.
- Identify missing information and potential risks.
- Document a human-review process.

## 4. Dataset

The demonstration dataset contains 10 fictional customer messages.

The five categories are:

- Order
- Refund
- Delivery
- Product Question
- Complaint

Two fictional messages represent each category.

## 5. Workflow

1. Prepare fictional customer messages.
2. Use an AI classification prompt.
3. Compare predicted categories with expected categories.
4. Generate draft responses using a second prompt.
5. Identify risks and missing information.
6. Review drafts using a human-review checklist.
7. Record results and document limitations.

## 6. Tools Used

- ChatGPT — AI-assisted message classification and response drafting.
- Notepad — Creating and editing project documentation and CSV files.
- Spreadsheet software — Intended for organizing and evaluating results, if used.

## 7. Human Review and Responsible AI

AI-generated content is treated as a draft, not a final decision.

A human must verify accuracy, tone, privacy, and business-policy compliance before any response is used.

The workflow must not invent order details, delivery dates, refund approvals, or product information.

## 8. Project Files

- `data/` — Fictional customer messages and classification results.
- `prompts/` — AI classification and response-generation prompts.
- `workflow/` — Workflow documentation and human-review materials.
- `report/` — Project report and findings.
- `evidence/` — Screenshots documenting actual project work.

## 9. Results

Actual classification results and review findings will be documented after the results have been verified.

No real-world productivity improvements or business performance claims are made.

## 10. Limitations

- The dataset contains only 10 fictional messages.
- The project does not use real customer information.
- No live customer support platform is connected.
- No real customer messages have been sent.
- The results do not establish real-world AI performance.
