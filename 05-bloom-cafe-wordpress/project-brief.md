# Bloom Café — Project Brief

## 1. Project Overview

**Project name:** Bloom Café — Responsive WordPress Business Website

Bloom Café is a fictional café business website created as a beginner portfolio project using WordPress.com. The project focuses on building a small-business website, organising its content, checking navigation, and testing its presentation across different screen sizes.

## 2. Project Goals

- Build and publish a simple café business website.
- Create clear Home, About, and Contact pages.
- Provide working navigation between the main pages.
- Check the website on desktop, tablet, and mobile screen sizes.
- Test the contact form using a sample submission.
- Review image alternative text and heading structure.
- Document testing results and website limitations.

## 3. Target Audience

The intended audience for this fictional business website includes people who want to learn about the café concept, explore its information, and use the Contact page.

## 4. Project Scope

### Included

- Three main pages: Home, About, and Contact
- WordPress.com hosting
- Twenty Twenty-Five theme
- Main page navigation
- Contact form
- Responsive layout checks
- Basic website testing and documentation
- Screenshots for portfolio evidence

### Not Confirmed or Not Included in This Documentation

- Successful delivery of contact form email notifications
- Completed SEO title and meta description configuration
- Verified search engine visibility settings
- A downloadable copy of the complete WordPress.com site source code

## 5. Tools and Platform

- **Website platform:** WordPress.com
- **Theme:** Twenty Twenty-Five
- **Documentation:** Markdown
- **Repository:** GitHub
- **Testing:** Web browser and responsive layout checks
