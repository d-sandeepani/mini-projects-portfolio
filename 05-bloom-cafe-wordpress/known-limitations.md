# Bloom Café — Known Limitations

## 1. Project Context

Bloom Café is a fictional café business website built and hosted on WordPress.com using the Twenty Twenty-Five theme.

## 2. Current Limitations

### Contact Form Email Notifications

A test contact form submission was completed and the submission was restored from Spam to the normal Feedback list.

**Limitation:** Successful delivery of contact form email notifications has not been confirmed.

### SEO Title and Meta Description

SEO title and meta description fields were not found in the WordPress.com interface used during this project.

**Limitation:** Configuration of these fields has not been verified.

### Search Engine Visibility

The search engine visibility setting was not found in the interface during the project checks.

**Limitation:** The setting has not been verified. This document does not claim that search engines will or will not index the site.

### WordPress.com Source Files

The website is hosted on WordPress.com.

**Limitation:** This repository contains project documentation and screenshots; it is not a complete downloadable copy of the WordPress.com site's source code.

### Testing Evidence

The main pages, navigation, desktop/tablet/mobile layouts, and contact form have been reported as tested.

**Limitation:** Results represent the checks reported during development. Additional checks may be needed after website updates.

## 3. Future Verification

The following items can be reviewed in future project updates:

- Verify whether contact form notification emails are delivered.
- Review available SEO settings.
