# LIORA Website QA Testing Project

## Project Overview

This project focuses on manually testing the LIORA Fashion E-Commerce Website to evaluate its main pages, navigation, forms, shopping cart, and responsive layout.

## Project Type

Manual Website Testing

## Website

LIORA Fashion E-Commerce Website

## Testing Environment

- Local development environment
- XAMPP
- Localhost
- Desktop browser
- Mobile viewport testing at approximately 375px

## Testing Areas

- Page loading and navigation
- Product details
- Registration form validation
- Login form validation
- Add-to-cart functionality
- Cart quantity and total price updates
- Checkout form validation
- Image loading and link navigation
- Mobile responsiveness
- Page readability and layout consistency

## Tools Used

- Manual Testing
- Microsoft Excel for test cases
- Markdown for documentation
- Browser Developer Tools, where applicable
- XAMPP localhost environment

## Test Results

- Total Test Cases Executed: 23
- Passed: 23
- Failed: 0
- Not Run: 0
- Blocked: 0

No visible defects were reported in the 23 executed test cases. These results apply only to the scenarios tested and do not guarantee that the website is completely defect-free.
