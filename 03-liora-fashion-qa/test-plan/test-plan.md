# LIORA Fashion E-Commerce Website — Manual QA Testing & Test Documentation

## 1. Project Overview

This is a personal portfolio QA testing project based on my existing diploma project, LIORA — Fashion E-Commerce Website.

The website is run locally using XAMPP and localhost.

## 2. Testing Objectives

- Check whether website pages and features behave as expected.
- Identify and document actual defects.
- Check form validation and navigation.
- Evaluate basic responsive behaviour and usability.
- Record test results and supporting evidence.

## 3. Application Under Test

**Application:** LIORA — Fashion E-Commerce Website  
**Environment:** Localhost  
**Server tool:** XAMPP  
**Testing approach:** Manual testing

## 4. Initial Feature Inventory

The following pages have been confirmed to open:

- Home — `home.php`
- About — `about.php`
- Contact — `contact.php`
- Shop — `shop.php`
- Product Details — `product.php`
- Register — `register.php`
- Login — `login.php`
- Cart — `cart.php`
- Checkout — `checkout.php`

Opening a page does not confirm that all its features work correctly. Further testing is required.

## 5. Scope of Testing

Planned testing, where applicable:

- Page navigation and links
- Homepage and product display
- Product details
- Registration and login forms
- Cart functionality
- Checkout flow
- Form validation
- Responsive layouts
- Basic UI and usability
- Basic keyboard accessibility
- Retesting and regression testing

Only features confirmed to exist will be included in the final test results.

## 6. Out of Scope

- Penetration testing
- Formal security certification
- Payment processing verification using real payments
- Testing on every browser and physical device
- Features that are not present or cannot be accessed

## 7. Testing Types

- Functional testing
- UI testing
- Form validation testing
- Responsive testing
- Basic cross-browser testing, if available
- Basic usability testing
- Basic accessibility checks
- Regression testing, where applicable

## 8. Test Environment

- Operating system: Windows
- Local server: XAMPP
- Browser: Google Chrome
- Application URL: Localhost

Exact browser version, device viewport sizes and other environment details will be recorded during testing where relevant.

## 9. Test Data

Use non-sensitive test data only.

Do not use real customer information, real payment details or confidential credentials.

## 10. Entry Criteria

- The LIORA project files are available.
- The website can open on localhost.
- The relevant feature is accessible for testing.

## 11. Exit Criteria

- Planned test cases have been executed where possible.
- Actual results and statuses have been recorded.
- Observed defects have been documented.
- Blocked and untested cases have been identified.
- A test execution report and final summary have been prepared.

## 12. Risks and Limitations

- Some features may depend on database configuration.
- Some functions may not work even if their pages open.
- Testing is limited to the browsers and environments actually available.
- Manual testing cannot guarantee that the website is completely free of defects.

## 13. Reporting

Test cases, actual results, screenshots, observed defects and test summaries will be maintained in the LIORA QA Testing Project folder.

This is a personal portfolio project based on an existing diploma website. It does not represent employment at a real company.
